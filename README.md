## Publish on GitHub Pages (free)

1. Sign up at https://github.com/signup with the email
   Emergingtechnologiesapps@gmail.com and the username
   **emergingtechnologiesapps** (if it is taken, choose another and tell the
   developer so the app and site can be updated).
2. Create a repository: https://github.com/new
   - Repository name: **emergingtechnologiesapps.github.io** (must be
     `<your-username>.github.io` exactly)
   - Public, no README. Click **Create repository**.
3. On the new repository page click **uploading an existing file**.
4. Open this `website` folder on your computer, select **everything inside it**
   (`index.html`, `404.html`, `.nojekyll`, and the `assets`, `contact`,
   `privacy`, `terms` folders) and drag it onto the GitHub page. Do not upload
   the `website` folder itself, only its contents. Click **Commit changes**.
   - `.nojekyll` is hidden in Windows Explorer. It is optional; if you cannot
     see it, skip it.
5. Repository **Settings › Pages**: Source = **Deploy from a branch**,
   Branch = **main**, folder **/ (root)**, **Save**.
6. Wait 1–5 minutes, then open the four URLs above. All must load.
